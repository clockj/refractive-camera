# refractive-camera

Camera models that see through curved windows. For a 3-D point behind a cylindrical or spherical window
(a water-filled tube or a spherical tank), the projection finds every pixel where the point appears.
A point can have no image (the window hides it), one, or several.

> **Status: early development.** There is nothing to install yet. This repository will hold a standalone
> Python library and examples for robotics simulation in NVIDIA Isaac Sim.

## The method

S. Zhong, S. Tan, X. Zhang, Y. Li and R. Ni, "A complete forward projection algorithm through cylindrical
and spherical refractive windows", [arXiv:2610.17413](https://arxiv.org/abs/2610.17413) (2026).
